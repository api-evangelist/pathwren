# AI Crawler Index

A read-only, keyless reference dataset and toolset covering AI/web crawlers: what each crawler is for, its robots.txt token and user-agent substring, whether the operator obeys robots.txt, how to verify authenticity against operator-published IP ranges, and what a site loses by blocking it. Operated by Pathwren as CC0 static files with REST endpoints, OpenAPI, MCP servers, and llms.txt.
