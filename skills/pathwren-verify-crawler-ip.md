# Verify a crawler IP against operator-published ranges

## When to use this

A request arrived claiming to be GPTBot, ClaudeBot or Googlebot. Before you allow it privileged
access — or accuse it of forgery — check the address against what the operator itself publishes.

## Steps

1. **Find out whether the crawler is verifiable at all.** `GET /crawler/{slug}.json`
   (`getCrawler`) carries `verification_method`: `published-ranges`, `reverse-dns` or `none`. Only
   `published-ranges` can be answered from this API.
2. **Fetch the prefix union.** `GET /ip-ranges/all.json` (`getAllIpRanges`) returns every mirrored
   prefix in one schema — 1887 IPv4 and 1056 IPv6 prefixes across 12 sources at the 2026-09-01
   build. For a WAF paste, `GET /ip-ranges/all.txt` (`getAllIpRangesText`) is one CIDR per line.
3. **Narrow to one operator if you want provenance.** `GET /data/ip-sources.json`
   (`listIpSources`) lists which operators publish ranges and where;
   `GET /ip-ranges/{source}.json` (`getIpRangeSource`) returns that source's prefixes with the
   upstream URL, the operator's own timestamp and a SHA-256 of the bytes received. A 404 means the
   source slug is wrong — enumerate it from `listIpSources` first.
4. **Test containment locally** (`ipaddress` in Python, `net/netip` in Go). No endpoint accepts an
   IP address; the API publishes the prefixes and you do the match.

## Rules that matter

- **A miss is a miss, not a forgery.** An address outside every published prefix means only that
  the operator does not publish that range — the operator may not publish ranges at all, or may
  have added a range since the last mirror. Report it as unverified.
- **Check freshness before you act on a block.** `GET /status.json` reports `fetched_at`,
  `changed_since_last_fetch` and any failed source per row. Ranges are refreshed every six hours;
  a stale list makes a block fail open.
- Verification and identification are two different questions. Run this after
  `identify-crawler`, never instead of it.

## Conventions and errors

- Unauthenticated GET, no rate limit, CORS open. Cache on the `ETag`.
- `/ip-ranges/all.json` is the largest document on the host (~150KB); fetch it once and hold it
  for the six-hour cycle rather than per request.
